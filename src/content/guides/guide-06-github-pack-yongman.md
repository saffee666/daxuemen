GitHub Student Developer Pack 的申请步骤见钱条目「GitHub Student Developer Pack」（[官方入口](https://education.github.com/pack)）。多数人的问题是**领完就放着**——包里 200+ 个 offer 是分层级的，按下面的顺序取，一学期就能回本你投入的十分钟。

## 第一层：学业刚需（先取）

- **GitHub Copilot Pro 免费**：认证后直接在 Copilot 设置里绑学生身份，写代码、写注释、生成单测，全课程作业通用。
- **JetBrains 全家桶**：IDEA/PyCharm/CLion 学生授权，实验课用什么 IDE 就开什么；授权一年一续，GitHub 账号登录即可。

## 第二层：云与算力额度

- **Azure for Students**：$100 额度免信用卡，跑课程项目的小型后端、数据库、虚拟机足够一学期。
- **DigitalOcean / Heroku 等额度**：部署 demo、作品集站点用；额度类 offer 都有时限，别攒到毕业才想起来。

## 第三层：生产力与作品集

- **Canva Pro、Figma Education**：课程展示、海报、简历排版。
- **Namecheap 免费 .me 域名 + 托管额度**：作品集站点配域名，求职季链接直接写上简历。
- **Bootstrap Studio / Termius 等工具类**：按专业取用，领之前看清是「学生期免费」还是「一次性授权」。

## 第四层：证书与进阶

- 部分平台（如 DataCamp、Educative 类）给学习期会员：按课程规划取，别为了领而领。

## 避坑四条

1. **逐个 offer 激活**，认证通过 ≠ 全部到账；每个 offer 有自己的领取页与有效期。
2. **续验学籍**：GitHub 会定期要求重新验证学生身份，邮箱失联会被收回授权——申请邮箱用常用的。
3. **额度到期清零**：云额度类不叠加、不延期，项目立项时先查剩余额度。
4. **offre 口径常变**：包内清单以 [官方 offers 页](https://education.github.com/pack#offers) 实时展示为准；快照类攻略（包括本站）都可能滞后。
