Sketch 是 UI 设计老牌工具（Mac App + Web App + iPhone App）。学生和教师可申请**免费一年**：Education Workspace 带 50GB 存储和 Editor 席位，个人作业和小组协作都够用。

## 认证步骤（官方两步）

1. [下载 Sketch](https://www.sketch.com/education/)，开试用并建好 Workspace——**不用信用卡、不用付款信息**（已有 Workspace 的跳过）。
2. 填教育申请表，回答学生/教师身份并提交资格证明。

审核期间先用 **30 天全功能试用**顶着，通过后免费用满一年。

## 核心用法

画布画界面、组件库复用、原型跳转；和同学共享 Workspace 协作，小组作业一个文件多人改。

## 学生场景技巧

UI 课作业按真实设计规范画；App 大赛的 demo 原型从模板起步；作品集排版导出。学生/教师席位的细节差异（Editor 席位数）以官方 Common questions 为准。

## 权益边界与坑

1. **仅 macOS**——Mac App 要求 macOS Sequoia（15.0.0）或更新；Windows 同学用网页版凑合，重度使用建议直接上 Figma。
2. 审核期不固定，**别把作业截止日押在审核上**——30 天试用就是垫底用的，先干活再等转正。
3. 一年到期重新申请，在读期间可续。
4. 申请提交的身份信息只用于资格审核（官方页明示），按表单要求填即可。
