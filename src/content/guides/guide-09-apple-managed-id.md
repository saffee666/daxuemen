苹果给教育机构有一项常被忽略的福利：通过 [Apple 校园教务管理](https://www.apple.com.cn/education/k12/deploy-and-manage/)部署的 **Managed Apple ID**（教育版账号），官方页原文是「iCloud 空间，免费存」——**附带 200GB iCloud 空间，不对个人收费**。

## 资格边界（最重要的一节）

- 这是**机构型福利**：由学校 IT 部署 Apple 校园教务管理（Apple School Manager）后，给学生下发 Managed Apple ID；**个人无法自行申请**，任何「代开通」都是坑。
- 第一步永远是**问学校**：联系学校 IT 服务中心/信息办，问「学校有没有部署 Apple 校园教务管理、学生能不能领 Managed Apple ID」。中小学与高校都有部署案例，覆盖差异大。
- 学校没部署就没有这个通道，别在个人 Apple ID 上折腾任何「教育版 iCloud」。

## 拿到账号后的切换避坑

学校发给你账号密码后，按下面的顺序操作，能少踩九成的坑：

1. **确认账号版本**：教育版 Managed Apple ID 走苹果官方服务器；国内个人 Apple ID 涉及云上贵州（云上贵州运营的是个人 iCloud 方案），两者是不同体系，别混淆登录入口。
2. **iCloud 与 App Store 分离**：教育版账号只用于 iCloud；App Store 继续用你自己的个人 Apple ID——这样已购应用、订阅都不受影响。
3. **退出原 iCloud 前先备份**：设置里「退出登录」时选择**保留数据副本**，通讯录/照片/备忘录先留本地。
4. **首次登录改密码**，并绑定手机号，避免每次登录反复双重验证。
5. **验证空间**：登录后到 iCloud 设置里确认容量档位显示 200GB，再把照片/备份迁进来。

## 长期边界

- Managed Apple ID 归学校管理：密码重置走学校流程，**毕业或离校后账号可能被回收**——重要照片和备份保持「教育版 + 个人版」双份，别把唯一的家庭相册只放在学校账号里。
- 空间福利是苹果面向机构的现行政策，若学校调整部署方案，以学校 IT 通知为准。
