维权信写得快不快被处理，取决于受理人能不能在 30 秒内抓到四件事：你是谁、发生了什么（带日期和金额）、你要什么、不处理你会走什么渠道。情绪化长文不如要素齐全的短文。以下五套骨架覆盖学生最高发的争议场景；写信前先把对应的取证做完（网购维权路径见道条目「网购/快递维权路径」，退租争议见「退租被扣押金，四步拿回来」）。

## 通用骨架（先背这个）

```
【标题】事项 + 诉求关键词（如「关于X月X日订单XX号商家未发货的退款投诉」）
【身份】姓名 / 学校院系 / 联系方式（可选：学号、订单号）
【事实】按时间线列：X月X日做了什么 → X月X日发生了什么 → 现状是什么
【凭证】列附件：订单截图、聊天记录、付款凭证、合同照片
【诉求】明确金额与期限：请于 7 日内退还 XX 元至原支付渠道
【升级】如未解决，将通过 12315 平台 / 学校职能部门 / 消费者协会投诉
```

## 场景一：12315 消费投诉（网购/线下商家）

先在 12315 平台（12315.cn 或小程序）提交，投诉书正文套骨架，重点两处：**商家全称**（从订单页/营业执照照抄）和**明确诉求**（退款/换货/赔偿，写金额）。12315 受理后商家通常 7 个工作日内回应——平台调解成功率远高于自己跟客服扯皮。前提是你先向商家主张过一次并留下记录（聊天里发一句「请于 X 日内退款，否则将向 12315 投诉」，这就是主张证据）。

## 场景二：平台客服工单（外卖/打车/二手）

平台内投诉的要诀是**一次性给全要素**：订单号 + 时间线 + 诉求 + 已尝试的沟通记录。客服的权限按 escalate 层级解锁，第一轮客气但要完整，第二轮明确说「请转高级客服处理，我的诉求是 XX」。口头承诺（「稍后给您处理」）当场要求书面化——工单系统里的文字记录才是凭证。

## 场景三：押金催告函（退租）

退租被扣押金走完 [四步拿回来](../entries/pits-15-zujin-beikou-weiquan/) 的沟通未果后，发正式催告函（微信长文/邮件/纸质各留一份）：

```
【催告函】致出租人 XXX：
本人于 X 年 X 月 X 日签订《房屋租赁合同》（地址XX），已于 X 月 X 日
完成退租交接（附交接确认/水电气表照片），押金 XX 元按合同第 X 条应于
X 日内退还。截至本函发出之日尚未收到。
请于收函后 7 日内退还押金 XX 元。逾期未退，本人将向房屋所在地
人民法院提起小额诉讼（诉讼标的 XX 元，金额较小，一审终审），
并向 12345 反映相关情况。
本人联系方式：XXX
```

## 场景四：学校申诉（成绩复核/处分申诉）

学校场景的行文要点是**引用制度文件**：先查学生手册/教务规定里对应的条款号，信里写「依据《XX 大学成绩管理办法》第 X 条」，然后给证据（试卷、作业记录）与一个可执行诉求（复核第 X 题评分）。申诉有时限（常见为成绩公布后数日内），过期不候——先在期限内提交占位，再补材料。

## 场景五：银行/支付争议（盗刷/错误扣款）

银行 App 内的争议申请 + 客服电话双线提交，正文要素：争议交易的时间金额、发现方式、已采取的措施（挂失/冻结）。信用卡盗刷强调「非本人交易」并要求出具争议处理单号。涉及第三方平台的扣款（会员自动续费类），先在平台取消授权再向银行发起拒付，顺序别反。

## 一条时间纪律

所有维权动作都记在同一个地方（备忘录即可）：哪天发的信、承诺期限、到期日。**90% 的维权失败不是写不好信，是发出之后就忘了追**——到期没结果就升级到下一渠道，不要在同一家客服那里无限循环。
